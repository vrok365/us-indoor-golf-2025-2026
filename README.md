각 매장 행에는 근거 URL(`source`)이 포함됨.

## 4. 폴더 구조
```
new store/
├── us-indoor-golf-2025-2026.html   ← 결과물 (이것만 있으면 됨)
├── README.md                       ← 이 파일
└── _archive/                       ← 중간 산출물 (재빌드용, 평소엔 무시 가능)
    ├── build.mjs                   ← shard들을 합쳐 HTML 데이터 주입
    ├── geocode.mjs                 ← 도시 좌표 지오코딩
    ├── venues-data.json            ← 최종 513개 데이터(좌표 포함)
    ├── geocode-cache.json          ← 도시→좌표 캐시
    ├── us-states.json              ← 주 경계 GeoJSON(색농도용)
    ├── venues-*shard-*.json        ← 원본 수집 데이터(1·2·3차)
    └── brand-overrides*-shard-*.json ← 브랜드 보정 결과
```
